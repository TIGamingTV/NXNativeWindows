## NXNativeWindows 2026.11.04.2

A fix release for [v2026.11.04.1](https://github.com/TIGamingTV/NXNativeWindows/releases/tag/v2026.11.04.1): Switch 2 games build from the window.

### Fixed
- **Switch 2 games in the window** (`Build-IPA-GUI.bat`): the window now takes a Switch 2 game as one NUP container (a `.nup` file: *Add files*, or *Choose folder* on the folder that holds it) or as a folder of its files (`base\exefs`, `base\romfs`, optional `updates\<version>\` and `dlc\<title ID>\`; picking its `base` or `updates` folder finds it too), and builds the IPA itself, as for a Switch 1 game. Neither needs `prod.keys`: the keys step reads *Not needed*. Before, *Choose folder* was hidden until files were picked, found only NSP / XCI / NSZ / XCZ files, and the build always asked for `prod.keys`.
- **Choose folder** is always shown in the window.

### Unchanged
These builds need a game with a profile (the Switch 2 games in the games table). Install `zbic` once (`python -m pip install zbic`). From a terminal: `python win\build_ipa_windows.py <the .nup file or the game folder>`, with no `-k`. The Switch 2 games have not been played on a device with this port yet.
