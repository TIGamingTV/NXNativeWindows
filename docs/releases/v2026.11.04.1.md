## NXNativeWindows 2026.11.04.1

A fix release for [v2026.11.04](https://github.com/TIGamingTV/NXNativeWindows/releases/tag/v2026.11.04): the same features (Switch 2 games from upstream, the touch controls editor), with the build fixes CI found after it.

### Fixed
- **Mac host and its graphics tests** compile again: the memory guard's iPhone-only memory calls are built for iOS only.
- **Xcode iOS builds** link again: the split build's data-folder screen is Windows-build only, and an Xcode build now shows upstream's "game files not found" hint instead.
- **DLC of a split build**: the DLC folder inside the copied data folder is still found, now without changing upstream's DLC lookup (its startup tests pass again).
- **BC texture decoding** on A16 and older GPUs: endpoint and index arrays start zeroed (a static-analysis finding; no change in correct blocks).

### CI
- New **windows** workflow: the Windows port's tests (`win/tests/test_win.py`, including the subprocess shim's, which only run on Windows) and the docs checks on a Windows runner.
- The Mac checks now accept this port's tool lock (Windows Metal compiler and spirv-cross) and its `org.nxnativewindows` bundle IDs.
- Still open: four clang-tidy findings in files that are unchanged from upstream (`hle_jit.c`, `hle_oe.c`, `web_apple.m`, `hle_vk.m`), left for upstream to fix.

### Unchanged
On Windows, install `zbic` once for Switch 2 games (`python -m pip install zbic`). Mario Tennis Fever still needs its one-time NRO capture on the device (see the v2026.11.04 notes). The Switch 2 games and the editor have not been played on a device with this port yet.
