## NXNativeWindows 2026.11.04.3

A fix release for [v2026.11.04.2](https://github.com/TIGamingTV/NXNativeWindows/releases/tag/v2026.11.04.2).

### Fixed
- **Switch 2 game folders** (`base\`, `updates\`, `dlc\`) stopped at *pack v0* with `FileNotFoundError: [WinError 2]`: the upstream packer copies the ExeFS with macOS's `cp -c` (an APFS clone) and copies it itself only when `cp` fails, but on Windows `cp` does not exist at all. The Windows shim now runs `cp -c` as a plain copy, and `xattr` (the RomFS packer's guest names, only written by a Mac's extraction) as "no such attribute".

### Unchanged
Switch 2 games need a game with a profile and `zbic` (`python -m pip install zbic`); a NUP or a game folder needs no `prod.keys`. They have not been played on a device with this port yet.
