## NXNativeWindows 2026.11.04

### Switch 2 games, from upstream
Synced with [seedds/nxnative](https://github.com/seedds/nxnative) (393 commits). Upstream now plays Switch 2 games: Mario Kart World, Mario Tennis Fever, Donkey Kong Bananza, Splatoon Raiders, Fire Emblem Fortune's Weave, Hyrule Warriors: Age of Imprisonment and Pokémon Pokopia. Also Super Mario 3D All-Stars as one app of several games, AV1 movies, the in-game menu, TV output, cloud saves and many fixes.

On Windows:
- Install `zbic` once: `python -m pip install zbic` (Switch 2 code modules are ZBIC-compressed). `python win/doctor.py` checks it.
- Use `prod.keys` from a system new enough for the game.
- **Mario Tennis Fever** decodes its code at run time: the first build makes `<Game>-capture.ipa`. Install it, open it and press **Play** (it closes itself within seconds), copy its `nro_capture` folder from the Files app next to the game files, and build again.

### Touch controls editor
**Edit touch controls…** in the in-game menu (the gear): drag any control, resize it, hide it, and add shortcut buttons that press a button combination (hold, or toggle on and off). Saved per layout (2D / 3D) and per orientation. See [docs/playing.md](https://github.com/TIGamingTV/NXNativeWindows/blob/main/docs/playing.md#edit-the-touch-controls).

### Kept from this port
BC textures decoded on A16 and older GPUs (upstream refuses those devices), split builds, the memory guard and HUD, run-time captures on the device.

### Status
The whole app compiles from this source (267 files). The Switch 2 games and the editor have not been played on a device with this port yet; reports are welcome.
